# neu-nuxt

A **skin system for Nuxt UI v4** in plain Vue 3, with **neumorphism**, **glassmorphism** and
**neo-brutalism** presets and a full component showcase.

**Live showcase:** <https://matkg.github.io/nuxt-theming/>

```
neu-nuxt/
├─ packages/neu-ui/   # @neu-nuxt/ui — the library
└─ playground/        # the showcase (Vite + Vue + vue-router)
```

## The library

`@neu-nuxt/ui` re-exports every public Nuxt UI component with a `Neu` prefix and restyles the whole
system from design tokens. A skin is a theme object plus a scoped stylesheet; the component API
never changes. Built-ins:

- **Neumorphism** — clay surfaces, dual shadows, inset inputs.
- **Glassmorphism** — frosted translucent panels, hairline borders, aurora canvas.
- **Neo Brutalism** — thick ink borders, hard offset shadows, flat colour blocks, dotted paper.

```ts
// vite.config.ts
import vue from '@vitejs/plugin-vue'
import { skin } from '@neu-nuxt/ui/vite'

export default defineConfig({ plugins: [vue(), skin('glass')] })
```

```css
/* main.css */
@import "tailwindcss";
@import "@nuxt/ui";
@import "@neu-nuxt/ui/skins/glass.css";
```

Skins can be switched at runtime with `useSkin()` / `applySkin()` / `<NeuProvider :skin="…">`.

See [`packages/neu-ui/README.md`](packages/neu-ui/README.md) for the full API, skin authoring,
shared surface utilities and theming guide.

## Showcase

The playground is a documentation-style showcase (sidebar navigation, light/dark mode, command
palette, live skin switcher) covering:

- **Elements** — button, badge, alert, avatar, card, kbd, progress, skeleton, chip, separator, icons
- **Forms** — input, textarea, select, select menu, input menu, tags, checkbox, radio, switch,
  slider, number, rating, calendar, date/time, pin, upload, color picker, validation
- **Navigation** — tabs, accordion, breadcrumb, pagination, navigation menu, stepper, command palette
- **Overlays** — modal, slideover, drawer, dropdown, context menu, popover, tooltip, toast
- **Data** — table, timeline, user, tree, collapsible
- **Layout** — page hero/section/card, empty state, dashboard app shell
- **Theming** — skin switcher, palette, shared surface utilities, tokens, integration modes
- **Catalog** — all exports

The showcase is deployed to GitHub Pages by
[`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) on every push to
`master`. GitHub Pages must be enabled with **Source: GitHub Actions** in the repository settings;
the workflow builds with `GITHUB_PAGES=true`, which sets the Vite base path to `/<repo>/` and
ships a `404.html` fallback so deep links work.
